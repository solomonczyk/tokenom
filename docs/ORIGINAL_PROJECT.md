# Original Project

Tokenom is a security-hardened derivative of Headroom.

- Original project: https://github.com/chopratejas/headroom
- Original license: Apache License 2.0
- Original copyright and attribution remain in the repository.
- The original `LICENSE` file is preserved.
- The original `NOTICE` file is preserved because it was present upstream.

Tokenom does not claim the original Headroom code as fully ours. Tokenom adds a
separate security hardening layer and supporting documentation on top of the
Headroom codebase.
